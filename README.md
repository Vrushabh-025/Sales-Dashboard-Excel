# Sales-Dashboard-Excel
📊 Sales Dashboard — Excel
Project Overview

This project analyzes sales data using Microsoft Excel to understand overall sales performance and identify trends across different regions, products, categories, and sales channels. The dashboard provides an interactive view of key sales metrics and helps compare business performance across different areas.

Dashboard Features

The dashboard includes key metrics such as Total Revenue, Total Orders, Total Quantity Sold, and Average Order Revenue. It also provides analysis of monthly revenue, revenue by region, product category, sales channel, and top-performing products.

Key Insights

Computers generated the highest revenue among all product categories.
Gaming Laptop was the top-performing individual product.
The North region generated the highest revenue.
Online sales were the strongest among the different sales channels.
November recorded the highest monthly revenue.
July recorded the lowest monthly revenue

🎯 Project Objective

The objective of this project was to analyze sales data and create an interactive Excel dashboard that provides a clear overview of sales performance and helps identify important business trends.
